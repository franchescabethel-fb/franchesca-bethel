# franchesca-bethel

Personal website for Franchesca Bethel — replaces the Linktree.

- `index.html` — home: ventures (Marketing Maison, Monet's Styling, Be You For You, travel), about, free pick-my-brain session, collabs, Amazon storefront, socials
- `press.html` — press & media kit: bios (copy buttons), fast facts, interview topics, downloadable press photos
- `style.css`, `script.js` — shared styles and small interactions
- `images/` — web-sized photos · `press-kit/` — high-res downloads

Hosted with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
