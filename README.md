# franchesca-bethel

Personal website for Franchesca Bethel — "Issue Nº 01", a magazine experience that replaces the Linktree.

- `index.html` — cover, contents, choose-your-door ventures, editor's note, about section + vinyl player, horizontal look book, pick-my-brain letter, collab report, boarding-pass travel inquiry, Amazon picks, socials, back cover
- `press.html` — the Press Room: bios (copy buttons), fast facts, interview topics, featured press
- `style.css`, `script.js` — shared design system and interaction engine
- `vendor/` — GSAP, ScrollTrigger and Lenis (bundled locally, no CDN needed)
- `images/` web photos

Respects `prefers-reduced-motion` (animations off, all content visible).

Hosted with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
